# CalStack

Googleカレンダーで会社の予定を自分のカレンダーへコピーして使うときに、重複した予定を画面上でひとつにまとめるChromium用拡張機能です。Chrome・Vivaldiへ読み込めます。自分側のタイトル行の端に小さな重なる四角形の印が付き、クリックすると自分側の詳細を開きます。

**対応：日本語表示のGoogleカレンダー／月・週・日表示／Chrome・Vivaldi**

Google Calendar API、追加のGoogle認証、外部サーバーは不要です。予定のデータは変更せず、ブラウザーでの表示を調整します。Chromeウェブストアでの配布には対応しておらず、手動で読み込んで使います。

## インストール

1. このリポジトリの **Code → Download ZIP** からダウンロードし、ZIPを展開します。Gitを使う場合は次のコマンドでも取得できます。

   ```sh
   git clone https://github.com/shirafukayayoi/CalStack.git
   ```

2. Chromeのアドレスバーに `chrome://extensions/` と入力します。Vivaldiでは `vivaldi://extensions/` を開きます。
3. 「デベロッパーモード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」を押します。
5. 展開したフォルダー内の **extensionフォルダー** を選びます。たとえば `CalStack-main/extension` です。プロジェクト全体ではなく、`manifest.json` があるフォルダーを選んでください。
6. 開いているGoogleカレンダーを再読み込みします。
7. 必要に応じてChromeの拡張機能メニューからCalStackを固定します。

Node.jsやnpmはインストール時に必要ありません。拡張機能はextensionフォルダー内のファイルだけで動作します。このフォルダーは読み込み後も同じ場所に置いてください。

## 設定と使い方

1. 日本語表示のGoogleカレンダーを開き、最初は会社側とコピー先の両方のカレンダーを表示します。
2. CalStackのアイコンを押します。
3. 「会社のカレンダー」と「自分のカレンダー」を選びます。同じ名前のカレンダーには識別用IDを併記します。
4. 「重複予定をまとめる」にチェックし、「設定を保存」を押します。

月・週・日表示で利用できます。タイトル（前後の空白を除く）・開始日時・終了日時・終日区分が一致した予定だけをまとめます。説明文、場所、参加者は一致条件に含めません。コピー元との関係を証明する機能ではなく、指定した2つのカレンダーの一致を見つける機能です。

会社の未コピー予定は残ります。別カレンダーの予定や、同じ側に候補が複数ある予定はまとめません。繰り返しは各開催日で判定し、複数日予定は期間全体で比較します。表示されていない予定は取得しないため、月表示の「他○件」内などに隠れたコピーを使って新たに重複判定することはありません。

### 会社側を非表示にして使う

両方を表示して有効にすると、その期間で確認できた一致を記録します。その後、会社側のチェックを外しても、自分側に一致の印が残ります。カレンダーを再読み込みしても記録は残ります。まだ一度も確認できていない期間の予定に印を付けたい場合は、その期間で会社側を一度表示してください。

印は予定の文字色を引き継ぎ、タイトルや時刻とは別の領域に表示します。

- **後ろの四角が塗り付き**：表示中の会社予定とタイトル・日時が一致しています。
- **両方とも輪郭のみ**：会社側が非表示で、前回確認した一致を示しています。

予定にカーソルを合わせるか、キーボードで予定にフォーカスすると、カレンダー名と一致状態を説明します。会社側が非表示の場合はカレンダー名と「現在の変更・削除は未確認」と表示します。確認日時は表示しません。Escapeで説明を閉じられます。印のための新しいTab移動先は追加しません。クリックは自分側の詳細を開きます。

非表示中の会社側の変更や削除は確認できません。会社側を再表示すると、画面で確認できる対応を更新します。記録は確認から30日で失効し、カレンダーの組み合わせごとに最大2048件を保持します。

設定はログイン中のアカウントのメールアドレスごとに、Chromeの端末内ストレージへ保存します。初期状態は未設定・無効です。ポップアップのチェックを外して保存すると、印・非表示・配置変更を元に戻します。拡張機能そのものを無効にした直後に表示が残る場合は、カレンダーを再読み込みしてください。

## データと制限

- 必要な権限はGoogleカレンダーのページへのアクセスと設定保存のみです。外部サーバー、Google Calendar API、追加のGoogle認証を使用しません。
- 予定は画面内で読み取ります。タイトル・日時・予定本文をそのまま保存したり、外部へ送信したりしません。保存するのはアカウント識別子、選択したカレンダーID、有効状態、確認済みの一致のSHA-256ハッシュと確認時刻です。ハッシュはタイトル・日時・終日区分から作成し、端末内だけで照合します。
- 予定のコピー・同期・削除・変更は行いません。通知、検索結果、印刷、スマートフォン、スケジュール表示は対象外です。
- 初版の予定説明文解析は日本語表示向けです。Googleの画面構造が変わった場合や必要な情報を取得できない場合は、対象の予定を通常表示に残してポップアップに状況を表示します。印を置くタイトル行を識別できない場合も、その重複を隠しません。
- 時間指定の枠を表示上の縦位置・高さで再配置します。未知の配置形式では幅の調整を行いません。Google側のドラッグ操作は元の配置情報を持つため、予定をドラッグで移動する際はCalStackを一時的に無効にしてください。編集後は再判定します。
- Googleの「他○件」や日別の予定件数は元の件数が残ります。月・終日欄の表示可能な予定の行は詰めますが、隠れた予定の読み込みやGoogle側の件数・画面全体の高さは変更しません。

## 更新・削除

最新版をダウンロードして同じ場所のファイルを更新するか、Gitで取得した場合はリポジトリ内で `git pull` を実行します。その後、Chrome・Vivaldiの拡張機能管理画面でCalStackの再読み込みボタンを押し、Googleカレンダーも再読み込みします。削除するときは同じ画面の「削除」を使います。

## 開発と検証

Node.js 24で確認しています。

```powershell
npm ci
npm test
node tests/serve.cjs
```

検証用サーバーは端末内の `127.0.0.1:8765` だけで待ち受けます。`http://127.0.0.1:8765/calendar/u/0/r/week` をChromeで開き、「検証を実行」を押すと、架空の予定で重複統合・印・未コピーの保持・自分側の詳細・無効化後の復元を確認できます。月・日表示へも移動できます。「印の見え方」では短い枠、狭い列、長いタイトル、明暗色を確認できます。終了はサーバーを起動したターミナルで `Ctrl+C` を押します。

自動テストは判定、重なり配置、DOMの復元、再描画、アカウント別設定、ポップアップを対象にしています。Chrome検証画面はstorageとメッセージAPIの代替実装を使うため、実際に拡張機能として読み込む確認とは別です。

現在の自動テストは46件です。GitHub Actionsでもプッシュとプルリクエスト時にテストを実行します。検証用データには架空のカレンダー名と予定を使用しています。

### ファイル構成

| パス | 内容 |
| --- | --- |
| `extension/` | ブラウザーへ読み込む拡張機能本体 |
| `tests/` | 自動テスト、架空の予定を使う検証画面 |
| `.github/workflows/tests.yml` | GitHub Actionsによる自動テスト |
| `package.json` / `package-lock.json` | 開発・検証用の依存関係 |

## 実カレンダーでの確認手順

インストール後、両方に同じ予定がある期間で次を確認してください。

1. 月・週・日表示で会社側の重複が消え、自分側に印が付く。
2. コピーしていない会社の予定が残る。
3. 自分側をクリックすると、自分側の予定の詳細が開く。
4. 予定を通常の編集画面で変更すると重複判定が更新される。
5. 会社側を非表示にしても確認済みの印が残り、再読み込みしても保持される。
6. 日付移動・自分側非表示・無効化後も、必要な予定が消えたままにならない。

問題があれば無効化して保存するか、拡張機能を無効にしてカレンダーを再読み込みしてください。Googleの予定データに変更はありません。
